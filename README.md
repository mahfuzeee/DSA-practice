# DSA Practice

This repository contains a collection of JavaScript-based Data Structures and Algorithms practice exercises. It is organized as a learning workspace for common DSA concepts, problem-solving patterns, and implementation practice.

## Contents

### Core exercises

- `bracket-stack.js` — stack-based bracket matching logic
- `erase-duplicate.js` — duplicate removal exercise
- `expression-sum.js` — arithmetic expression evaluation / sum logic
- `fccPractice.js` — practice problems and algorithm experiments
- `linked-list.js` — custom linked list implementation
- `path-in-grid.js` — grid path traversal problem
- `recursion.js` — recursion examples and exercises
- `smallest.js` — smallest value / smallest element problems
- `subset-sum.js` — subset sum-related logic
- `three-sum.js` — three-sum problem practice
- `triplet.js` — triplet-based array problems
- `unique-character.js` — unique character detection exercises

### Dynamic programming

- `DynanicAlgorithm/` — dynamic programming practice problems
  - `knapsack.js`
  - `lone-zero-counter.js`
  - `zero-or-one.js`

### Greedy algorithms

- `greedyAlgorithm/` — greedy problem solutions
  - `activitySelection.js`
  - `colorfulArray.js`
  - `makeThemEqual.js`

### Hash map practice

- `hash-map-op/` — custom hash map implementation and examples
  - `hashmap.js`
  - `main.js`
  - `README.md`

## Goals

This project is intended to help practice:

- arrays and strings
- linked lists
- stacks and queues
- recursion
- hash maps and hashing
- greedy techniques
- dynamic programming
- problem-solving patterns in JavaScript

## Run examples

You can run individual JavaScript files with Node.js:

```bash
node linked-list.js
node subset-sum.js
node hash-map-op/main.js
```

## Notes

This repository is primarily for learning and experimentation, so the solutions focus on understanding problem-solving techniques and data structure behavior rather than production optimization.
